## Install in 3 Steps (Windows):

### 1. Download
```
https://github.com/UB-Mannheim/tesseract/wiki
Click: tesseract-ocr-w64-setup-5.3.3.exe
```

### 2. Install
```
Run the .exe file
Click Next → Next → Install
```

### 3. Restart
```
Restart XAMPP Apache
```

✅ **Done!** OCR Auto-Fill now works.

---

## Test It:

1. Log in as SPED Teacher
2. Go to IEP Meeting → PDSP Form
3. Upload signed document (clear photo)
4. Click **"OCR Auto-Fill"** button
5. Wait 5-10 seconds
6. Review pre-filled data
7. Correct any errors
8. Save

## Verify Installation:

Open Command Prompt:
