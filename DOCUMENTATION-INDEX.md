## 📖 Quick Reference

### For Setup
1. Read **README.md** first
2. Follow **SETUP-AND-TESTING-GUIDE.md**
3. (Optional) Configure Google OAuth using **GOOGLE-OAUTH-SETUP.md**

### For Testing
1. Use **PROCESS-1-TEST-CHECKLIST.md** for comprehensive testing

### For Development
1. Read steering files in `.kiro/steering/`
2. Follow **workflow.md** for development process
3. Update **CHANGELOG.md** after each feature
